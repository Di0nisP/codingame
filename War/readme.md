## Что реализовано

- Использование очередей (`std::queue`) для хранения карт игроков и временных карт на столе.

## Какие были идеи

- Первоначально была идея реализовать игру через рекурсию: каждый раунд как отдельный вызов функции `step`. Однако рекурсивный подход оказался слишком затратным и неудобным (риск переполнения стека и сложность управления состоянием), поэтому был заменён на итеративное решение с циклом `while`. Тем не менее рекурсия работает.
- Для отладки писалась вспомогательная функция `log` для вывода состояния очередей на каждом шаге.

## Сложности

- Отказ от рекурсии потребовал переработки логики ходов и счётчика раундов.
