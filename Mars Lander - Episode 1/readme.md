## Что реализовано

- Реализован расчёт критической высоты (`y_switch`), начиная с которой нужно включать тягу для замедления.
- Управление тягой ракеты в зависимости от текущей скорости и высоты.

## Какие были идеи

- Использовать физическую модель: свободное падение при ускорении Марса `g = 3.711` и расчёт безопасного торможения.

## Сложности

- Определение правильной высоты переключения на торможение, чтобы не включить двигатель слишком рано или слишком поздно. 
- Ввод корректирующего параметра `s3` для компенсации вертикальной скорости с учётом задержек включения тяги.
- Баланс между физической моделью (формулами) и ограничениями задачи (дискретные значения тяги и шагов).

> [!warning]
> Возможно, используемая формула для расчёта высоты переключения тяги неверна, однако она даёт достаточный результат для решения задачи с учётом ограничений.
