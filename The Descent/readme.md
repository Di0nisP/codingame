## Что реализовано

- Используется вектор для хранения высот всех гор за один ход.
- Определение максимального значения через `std::max_element` и получение индекса через `std::distance`.

## Какие были идеи

- Сохранять все высоты в массиве за один цикл, чтобы потом искать максимум.
- Использовать стандартные алгоритмы STL вместо ручного поиска максимума.
- Обеспечить читаемость кода за счёт `constexpr` и предвыделения памяти вектора.

## Сложности

- Учитывать, что цикл бесконечный и данные обновляются каждый ход, поэтому нужно правильно очищать и заново заполнять вектор.
