## Что реализовано

- Преобразование входного текста в верхний регистр и построение построчного вывода: для каждой строки шрифта и для каждого символа текста берётся соответствующий фрагмент длины `l` и конкатенируется в итоговую строку, затем печатается.
- Непечатные/неалфавитные символы заменяются на 27-й символ (индекс 26 — знак вопроса).

## Какие были идеи

- Представить шрифт как вектор строк длины h, где каждая строка содержит подряд 27 блоков по `l` символов. Для символа вычислять индекс: 'A'..'Z' -> 0..25, иначе -> 26.
- Для построения каждой строки результата последовательно брать `substr(idx * l, l)` из строки шрифта и добавлять в буфер.
- Применить `toupper` к каждому символу для корректной работы с знаковыми `char`.

## Сложности

- Важно приводить к `unsigned char`, чтобы избежать неопределённого поведения для отрицательных значений `char` (в коде это учтено).
