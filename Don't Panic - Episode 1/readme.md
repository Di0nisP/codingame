## Что реализовано

- Сохранение позиций всех лифтов и выхода в вектор `floor_pos`, сортировка по этажам.
- Проверка направления движения клона и решение: ждать (`WAIT`), если он движется в нужную сторону, или развернуть (`BLOCK`), если в противоположную.

## Какие были идеи

- Хранить лифты и выход в одном контейнере, чтобы обрабатывать этажи единообразно.
- Использовать сортировку по этажам, чтобы легко находить целевую позицию для клона.
- Минимизировать количество шагов до команды `BLOCK`, чтобы не тратить время впустую.
