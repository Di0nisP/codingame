## Что реализовано

- Решение задачи методом бинарного деления области поиска.
- Используются структуры `Position` и `Area` для удобной работы с координатами и ограничивающим прямоугольником.
- На каждом шаге область поиска сокращается в зависимости от направления (`U`, `UR`, `L` и т.д.), а новая позиция выбирается как центр оставшейся области.
- Для удобства созданы методы `fix_x` и `fix_y`, чтобы зафиксировать координату, когда направление не меняется.

## Какие были идеи

- Представить задачу как двумерный бинарный поиск: каждое направление сужает диапазон по `X` и/или `Y`.
- Использовать целочисленное деление при вычислении нового центра, чтобы гарантировать корректные координаты в сетке.

## Сложности

- Правильная обработка составных направлений (например, `UR`, `DL`), чтобы корректно сужать область сразу по двум осям.
- Контроль корректности диапазонов после каждого шага: не допустить выхода за границы здания.
- Баланс между округлением в `ceil`/`floor` — выбор целочисленного деления оказался более устойчивым для задачи.
