## Что реализовано

- На основе простых условий корректировка минимального модуля для отрицательного и положительного диапазонов температур.

## Какие были идеи

- Вести отдельный учёт минимальной положительной и максимальной отрицательной температуры.
- Использовать булевы флаги (`allow_negativ`, `allow_positiv`) для проверки, были ли вообще такие значения.
- Сравнивать по модулю значения отрицательной и положительной температуры, чтобы выбрать ближайшее к нулю.

## Сложности

- Корректная обработка граничных случаев.
